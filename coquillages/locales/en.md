# English — Visitor-facing copy

The identifiers match the same passages in all three languages. Notes in square brackets are production notes.

## start

- title: How does a shell grow?
- body: Come closer and watch a sea snail’s shell grow.
- action: Go underwater

## animal

- title: This is a sea snail.
- body: Its shell protects its soft body.
- action: Watch the snail
- after: The shell is part of the snail. The snail makes it itself.
- next: How does it get bigger?

## edge

- title: Where does the shell grow?
- instruction: Touch the place where you think it grows.
- old-area: The tip
- growth-area: The edge of the opening
- old-feedback: This is where the shell began. New material is added at the edge of the opening.
- correct-feedback: Right here. The animal adds new shell at the edge.
- detail-action: How does it do that?
- detail: A tissue in the snail’s body makes the shell. It is called the mantle. The shell is mostly calcium carbonate, with a little organic material.
- thickness: The shell can also get thicker on the inside.
- next: Watch the shell grow

## growth

- title: Watch the shell grow.

- earlier: Earlier
- later: Later

- after: Can you still see the little tip? It was there at the start. New shell has been added at the edge.

## bivalve

- title: How does a mussel’s shell grow?

- open: Open the shell

## Language note

Use everyday language rather than translating German sentence structures word for word. “Mussel” names the animal; “shell” names its shell. The production illustration must therefore show a compatible mussel example. No illustrated animal is presented as a confirmed museum specimen.
